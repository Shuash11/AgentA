### 1.1 The owner's pick is REAL — verified live (HF, 2026-11-02)

- **`Qwen/Qwen3.5-2B` exists** (`huggingface.co/Qwen/Qwen3.5-2B`): tagged Image-Text-to-Text (a vision-language model: "Causal Language Model with Vision Encoder"), apache-2.0, 3,431,121 downloads, updated Mar 2, 2026; a `Qwen/Qwen3.5-2B-Base` sibling exists. **The owner's name is not a phantom** — no nearest-substitute needed.
- **Architecture (vendor card)**: 2B params, hidden 2048, **24 layers in a hybrid layout `6 × (3 × (Gated DeltaNet → FFN) → 1 × (Gated Attention → FFN))`** — 18 linear-attention (DeltaNet) layers + 6 standard GQA layers (8 Q heads / 2 KV heads, head dim 256); token embedding 248,320 (padded, tied to output); context **262,144 native**; MTP trained. - **Benchmarks (vendor card table, fetched 2026-11-02)** — the owner's figures verified EXACT: MMLU-Pro (thinking) **66.5** vs Qwen3-1.7B **56.5** (and Qwen3-4B-2507 74.0); multilingual MMMLU (thinking) **63.1** vs **57.0**; MMMLU (non-thinking) 56.9 vs 46.7; MMLU-Pro (non-thinking) 55.3 vs 40.2; GPQA (thinking) 51.6 vs 40.1; IFEval (thinking) 78.6 vs 72.5; C-Eval (thinking) 73.2 vs 68.1; MMLU-Redux (thinking) 79.6 vs 73.9. ### 1.5 The thinking mechanics — verified (fluttergemma.dev /docs/thinking-mode, 2026-11-02)

- **Core parses `` tags for `ModelType.deepSeek`, `qwen`, `qwen3` AND `qwen35`** — "parsed by core for … `qwen35`" — so a thinking Qwen3.5 streams its reasoning as **`ThinkingResponse`** (with `response.content`) alongside `TextResponse` tokens, automatically, through the chat API.
- `createChat(enableThinking: …)` exists in core (the docs' example: `model.createChat(enableThinking: true, maxOutputTokens: 2048, modelType: …)`). The models-page example also shows `enableThinking` threaded from install-time runtime defaults.
- **`ModelThinkingFilter` handles `.gguf`**: turn markers (`<|im_end|>`, `<end_of_turn>`) "are stripped only for `.bin`/`.tflite` and `.gguf` files — on `.task` and `.litertlm` the runtime already ends the turn"; the reasoning-block removal covers `师长…师长` "for DeepSeek and the Qwen types".
- **The thinking budget is litertlm-only** (`LiteRtLmEngine(thinkingTokenBudget: …)` — not available on the llama engine). The llama path's loop guard is therefore: thinking OFF by default + `maxOutputTokens` (thinking counts toward it) + streaming with visible progress + stop/interrupt (`chat.session.stopGeneration()`) + the app's stall watchdog (§4.6).
- Always-reasoning vs optional: Qwen3.5-2B is an OPTIONAL thinker (non-thinking default) — with thinking off, no time/token cost, no `NOTE` spam.
